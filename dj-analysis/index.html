DJ Analysis Tool

Hello! You have found my DJ analysis tool. The purpose of this tool is to make it easy for people to extract and compare data from musical performances using a plethora of AI-based analysis tools (namely, Audio Data with various Essentia.js models, Facial Expressions with face-api.js, and Pose Detection from tfjs for motion detection). This project is intended as a tool for collecting data from DJ set videos (like Boiler Room) in order to compare audience energy to musical decisions made by the DJ.
